## 10G 还是 40G：按资源需求选

如果服务只有少量常驻进程，内存占用很低，月流量也能控制在 500 GB 以内，10G 可以作为轻量入门方案。不过 512 MB 内存余量有限，系统、Web 服务和数据库一起运行时，需要认真管理资源。

40G 更适合需要更多内存和流量余量的场景。它的 2 GB 内存对小型网站或多个轻量服务更从容，2 TB 月流量也适合数据传输需求较高的应用。考虑到年价只高 10 美元，若确认库存和实际结账金额与公开资料一致，预算允许时 40G 的配置更宽裕。
